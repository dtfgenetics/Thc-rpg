# Vertical Slice v2

This branch establishes the first executable THC RPG browser-game slice.

Validation completed before merge:

- 17 core regression tests pass
- Browser modules pass Node syntax checks
- Save version 1 migrates to version 2
- Currency has one authoritative source
- Invalid genetics cannot consume seeds
- Plant hydration, stress, health, yield, and quality are simulated
- Quest rewards cannot be claimed twice
- Asset/data paths are relative for subdirectory deployment
- Mobile travel and grow-room action restrictions are implemented

Next milestone: browser playtest and production art/environment systems.
